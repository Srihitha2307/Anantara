# Anantara

Explainable exoplanet triage: upload a light curve and/or a transmission spectrum, get a 3D system view with transit vetting (1D CNN),
habitable zone, cosmic shoreline and atmosphere candidate indications (2D CNN). Candidate indications, never life found.
Source and notes: see the GitHub repository.
